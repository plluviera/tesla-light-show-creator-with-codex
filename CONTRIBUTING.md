# Aportar resultados

Para reportar un ensayo, indicar modelo/año, firmware, mercado si se conoce,
canales con numeración desde 1, bytes enviados, tiempos y respuesta observada.
Separar lo observado de lo supuesto. No extrapolar un vehículo a todos los Juniper.

No adjuntar música sin permiso, videos privados, matrículas, ubicación o archivos
con metadatos personales. Un cronograma y una prueba con audio sintético suelen
ser suficientes para reproducir un hallazgo. No publicar credenciales ni rutas
privadas. Los aportes de código deben pasar la suite y mantener el diagnóstico
libre de dependencias externas.

Proponer nuevos canales como experimentales hasta tener evidencia reproducible.
No modificar el perfil conservador silenciosamente para introducir mecánicos,
control de píxeles o comandos no comprobados.
